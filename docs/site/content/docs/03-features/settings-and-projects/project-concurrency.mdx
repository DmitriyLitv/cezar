The project limit controls how many of its tasks can run together. A project uses one active task by default. Different projects can run at the same time until they reach the global limit.

## Where to find it

Settings → Global → Projects → Max parallel tasks for the project

## How to use it

1. Open project settings and set the parallel task limit.
2. Check how many tasks are running and how many are waiting in the queue.

> **Good to know**: Leave the project limit empty to use the default of 1. Raising it does not reserve extra resources or increase the global limit. Tasks wait in the queue when their project's slot is occupied. A live agent waiting for input releases its global slot but keeps its project slot, so replying cannot overlap another agent in the same project.
